# Pocket Password Storage
Pocket Password Storage is a offline password manager based on ESP32 board.

Current firmware version: `1.3.0`
> Firmware versions:
> * `1.0.0` - Basic encryption. Basic UI.
> * `1.1.0` - Errors fixes. WebUI created.
> * `1.2.0` - Basic and important functions work. Still requires troubleshooting and tests.
> * `1.2.1` - Board UI improvements. Text styling. New device PIN input.
> * `1.3.0` - New features: WiFi mode live update, Changing device PIN, PIN input fix.
