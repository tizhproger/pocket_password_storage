# Pocket Password Storage
Pocket Password Storage is a offline password manager based on ESP32 board.

Current firmware version 1.2.0 - Basic and important functions work. Still requires troubleshooting and tests.

> Firmware versions:
> * __1.0.0__ - Basic encryption. Basic UI.
> * __1.1.0__ - Errors fixes. WebUI created.
> * __1.2.0__ - Basic and important functions work. Still requires troubleshooting and tests.
> * __1.2.1__ - Board UI improvements. Text styling. New device PIN input.
> * __1.3.0__ - New features: WiFi mode live update, Changing device PIN, PIN input fix.
