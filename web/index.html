Record

Separate tags with commas. Up to 8 tags, 32 UTF-8 bytes each. Tags use one additional field.

Additional fields

Up to 8 fields including tags; each value can contain up to 512 UTF-8 bytes. Values are hidden in the records list until revealed.

Recovery phrase

Enter the words in their original order. Paste a complete phrase into the first cell, or several words into any cell. Nothing is saved until you apply the phrase and save the record.

Input helper only: words and wallet checksum are not verified. Keep the original phrase exactly as issued by your wallet.

Encrypted copy

A separate password will protect the backup file. Without it, recovery is impossible.

Replace records?

All current records will be replaced with the contents of the file. Save a backup first.

Restore previous records?

Current records will be replaced with the previous valid snapshot. The snapshot is retained until the next write attempt; even a failed attempt may replace it. Save an external backup before importing. Your current master password and PIN will be preserved. All sessions will be locked.
